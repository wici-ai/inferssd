# InferSSD engine

The InferSSD inference engine: model loading, the SSD expert store, the CPU,
CUDA and Metal backends, and the OpenAI-compatible server. It is derived from
llama.cpp and ggml. Their license is in [LICENSE](LICENSE), and attribution for
every bundled component is in [NOTICE](../NOTICE). Build instructions are in the
[quick start](../docs/quickstart.md).

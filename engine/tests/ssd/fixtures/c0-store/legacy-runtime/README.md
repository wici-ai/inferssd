This directory preserves the historical process-global C0 publication and environment adapter solely for the experiments/c0-store legacy tests. It is never installed, included or linked by the production store. Production source_index owns immutable explicit parser state and file descriptors per context. The shared legacy CPU/required-provider test DSOs use this code to retain historical precedence/publication assertions; their behavior does not describe the production ownership contract. Mature source parsing and O_DIRECT validation remain in ggml-ssd/store/parser.cpp and are still compared to the frozen extraction oracle.

# Review lessons

What reviewing pull requests has taught, newest first. Each night the reviewer looks back at what merged:
what needed a follow-up fix or a revert, and what its review missed. A mistake that recurs becomes a rule in
[pull request review](review.md), and the lesson records which rule it became. A rule that a check can
enforce is better as that check.

Each entry: the date, the pull requests, what happened, the lesson, and the rule or check it became.
